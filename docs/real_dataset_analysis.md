# 真实工业缺陷数据集分析报告

## 1. 数据集来源

- 来源路径：`D:\Industrial-Surface-Defect-Inspection\data\raw\`
- 数据集类型：KolektorSDD2 风格工业表面缺陷数据集
- 原始规模：train 2331 对 + test 1004 对（每对含原图 + GT mask）
- 标签方式：`*_GT.png` 像素级标注，全黑 = OK，含白像素 = NG
- 图片格式：PNG
- 是否使用 mask：当前 V1.0 仅使用图像级标签（OK/NG），未使用像素级 mask 做评估

## 2. 样本子集说明

- OK 样本数量：30
- NG 样本数量：30
- 总样本数量：60
- 图片格式：PNG
- 样本来源：从 test 集中按类别均匀抽取
- 仅使用图像级标签（OK / NG），未使用像素级标注 mask

## 3. OpenCV 检测方法

对每张图片执行以下传统机器视觉流程：

1. 灰度化
2. 阈值分割（GRAY_THRESHOLD=200）
3. 形态学开运算 + 闭运算（kernel=5×5）
4. 缺陷面积统计（非零像素数）
5. 轮廓检测（RETR_EXTERNAL）
6. 根据面积阈值（THRESHOLD=100）判断 OK / NG

## 4. 检测指标

在 60 张真实工业缺陷样本上的检测结果：

| 指标 | 数值 |
|------|------|
| TP | 3 |
| TN | 30 |
| FP | 0 |
| FN | 27 |
| Accuracy | 55.0% |
| Precision | 100.0% |
| Recall | 10.0% |

> **关键发现**：当前基于固定阈值的 OpenCV 方法在真实工业数据上 Recall 仅 10%，即 30 张缺陷样本中有 27 张被漏检。这清晰展示了简单阈值方法在真实工业场景中的严重局限。

## 5. 典型成功案例

### TP 案例（正确检出缺陷）

3 张 NG 样本被正确识别为 NG，缺陷面积较大或灰度对比度较强，固定阈值可以检测到。

### TN 案例（正确识别合格品）

30 张 OK 样本全部被正确识别为 OK，无 FP。说明当前方法在"不过度报警"方面表现尚可（高 Precision），但这是以大量漏检为代价的。

## 6. 误检案例分析

当前子集 FP = 0，未出现误检。

但需要客观说明：30 张 OK 样本规模有限，不能代表真实工业环境一定无误检。在更大规模样本中，表面纹理、反光、污渍等因素可能导致 FP。

## 7. 漏检案例分析

27 张 NG 样本被漏检（FN），多数缺陷面积显示为 0。可能原因：

- **缺陷灰度与背景接近**：真实工业缺陷（如细微划痕、浅色斑点）在灰度上可能与正常表面差异很小，固定阈值 200 无法有效分离
- **缺陷对比度低**：KolektorSDD2 风格数据集中的缺陷通常非常细微，在灰度直方图上几乎不可见
- **固定阈值不适配**：当前 GRAY_THRESHOLD=200 是为模拟图片（黑色背景上的白色缺陷）设计的，真实数据缺陷特征不同
- **形态学处理可能抹掉细小缺陷**：开运算的去噪效果在真实数据上可能过度，把细小缺陷当作噪声清除了
- **缺陷面积太小**：真实缺陷面积远小于阈值 100，即使是正确分割的缺陷也可能因面积不足而被判为 OK

## 8. 当前方法局限

- 固定阈值鲁棒性有限，不同数据集、不同光照条件需要重新调整
- 对光照变化敏感，同一产线不同时段可能产生不同效果
- 对复杂纹理适应性不足，无法区分正常纹理变化和真实缺陷
- 对细小缺陷可能漏检，阈值参数难以同时兼顾大缺陷和小缺陷
- 不同数据集需要重新调参，缺乏自适应性
- 简单面积阈值忽略了缺陷的形状、位置、纹理等特征

## 9. 后续改进方向

短期（V1.1）：

- **Otsu 自适应阈值**：根据图像直方图自动计算最优阈值
- **局部自适应阈值**：对光照不均匀的场景更鲁棒
- **阈值参数对比实验**：在真实数据上扫描多个阈值，找最优参数
- **反转阈值逻辑**：尝试检测暗色缺陷（cv2.THRESH_BINARY_INV）

中期（V1.x）：

- **纹理特征提取**：LBP、GLCM 等方法提取纹理特征辅助判断
- **连通域过滤优化**：基于面积、长宽比、圆形度等过滤误检
- **更大规模真实数据验证**：扩大样本量，覆盖更多缺陷类型

长期（V2.0）：

- **YOLO 目标检测训练**：标注真实缺陷，训练专用检测模型
- **分割模型**：U-Net 等语义分割方法做像素级缺陷分割
- **OpenCV vs YOLO 量化对比**：在同一测试集上对比两种方法

## 10. 面试讲法

这个版本不只是用模拟图片跑流程，我专门接入了真实工业表面缺陷数据来做验证。数据集是 KolektorSDD2 风格的，里面有像素级标注的缺陷 mask。

我用当前的 OpenCV 固定阈值方法跑了 60 张真实样本（30 OK + 30 NG），结果是 Accuracy 55%、Precision 100%、Recall 只有 10%。30 张 OK 全对，但 30 张 NG 里只检出了 3 张。

这个结果其实正好说明了传统阈值方法的真实处境：在模拟图片上 100% 准确率，到了真实工业场景就明显不够用了。真实缺陷往往对比度低、面积小，和正常表面的灰度差异很微弱，简单的固定阈值根本检测不到。

我觉得这个对比本身就很有价值——它证明了为什么工业界需要更智能的方法。下一步我计划先用 Otsu 自适应阈值改善，然后对比 YOLO 训练的效果，形成一个从传统方法到深度学习的完整技术演进故事。
