# V0.2 发布说明

## 版本目标

在 V0.1 基础阈值分割流程之上，增加形态学预处理增强，用于减少图像噪声和填补缺陷区域断裂，提高检测稳定性。

## 新增功能

- 新增 `src/morphology.py` 模块：
  - `apply_open_operation()` — 开运算（先腐蚀后膨胀），去除小噪声点
  - `apply_close_operation()` — 闭运算（先膨胀后腐蚀），填补缺陷区域断裂
  - `apply_morphology()` — 组合调用，通过参数控制
- `config.py` 新增配置项：`MORPH_KERNEL_SIZE`、`USE_OPEN_OPERATION`、`USE_CLOSE_OPERATION`、`MORPH_OUTPUT_DIR`
- 主流程 `main.py` 在二值化后增加形态学处理步骤
- 缺陷面积统计和轮廓检测改为基于形态学处理后图像
- 每张图片额外保存形态学结果图到 `outputs/morphology/` 目录
- CSV 报表增加 `morph_image_path` 字段

## 形态学开运算的作用

开运算 = 先腐蚀 + 后膨胀

- 可以去除二值图中孤立的小白点（噪声）
- 平滑缺陷区域边缘
- 断开细窄的连接

## 形态学闭运算的作用

闭运算 = 先膨胀 + 后腐蚀

- 可以填补缺陷区域内部的小孔洞
- 连接相邻的断裂缺陷区域
- 使缺陷轮廓更加完整

## 处理流程

```
原图 → 灰度图 → 二值图 → 形态学处理图 → 面积统计 → 轮廓检测 → 标注图 → OK/NG 判断
```

## 当前局限

- kernel 大小固定为 5×5，未做自适应调整
- 开闭运算顺序固定（先开后闭），未支持反向
- 形态学参数未做系统性实验优化

## 后续计划

- 增加形态学参数实验和对比
- 尝试自适应 kernel 大小
