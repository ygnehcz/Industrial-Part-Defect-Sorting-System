# V0.3 发布说明

## 版本目标

在 V0.2 命令行检测流程之上，增加简单 GUI 界面，降低使用门槛，支持图形化操作检测流程。

## GUI 功能说明

- 启动方式：`python gui_app.py`
- 选择图片文件夹（带浏览按钮）
- 点击"开始检测"运行完整检测流程
- 显示检测总数、OK 数量、NG 数量
- 显示 Accuracy / Precision / Recall
- 显示推荐阈值
- 显示所有报表路径

### 架构调整

- 核心检测函数抽取到 `src/batch_detector.py`
- `main.py` 和 `gui_app.py` 共用 `batch_detector` 模块
- `main.py` 命令行流程保持可用

## 当前 GUI 局限

- 使用 tkinter 基础控件，未做复杂美化
- 不支持从 GUI 修改阈值参数
- 不支持实时预览图片
- 不支持单张图片检测

## 后续改进方向

- 增加阈值参数调节滑块
- 增加检测结果图片预览
- 支持单张图片选择和检测
- 增加进度条
