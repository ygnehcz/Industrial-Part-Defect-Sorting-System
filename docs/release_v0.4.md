# V0.4 发布说明

## 版本目标

增加 USB 摄像头 / 本机摄像头实时检测能力，支持实时画面处理和 NG 帧保存。

## 实时检测流程

```
摄像头采集 → 灰度化 → 阈值分割 → 形态学处理 → 面积统计 → 轮廓检测 → 画面标注 → OK/NG 判断
```

- 使用 `cv2.VideoCapture(0)` 打开默认摄像头
- 每帧执行完整的图像处理流水线
- 画面上实时叠加状态（OK/NG）和缺陷面积
- 检测到 NG 时自动保存异常帧

## 新增配置

`config.py` 新增：

- `CAMERA_INDEX` — 摄像头设备编号，默认 0
- `REALTIME_SAVE_DIR` — NG 帧保存目录
- `SAVE_NG_FRAME` — 是否保存 NG 帧

## 摄像头检测局限

- 当前基于简单阈值，对复杂光照场景鲁棒性有限
- 摄像头分辨率和帧率受设备限制
- 尚未做帧率优化，高分辨率下可能卡顿
- 仅支持单个摄像头
- 没有录制视频功能

## 后续改进方向

- 增加摄像头参数调节（分辨率、帧率）
- 增加多摄像头支持
- 增加视频录制和回放功能
- 增加帧率显示和性能优化
