# V0.5 发布说明

## 版本目标

增加 YOLO 深度学习对比框架，为后续从传统方法到深度学习的演进预留接口和文档。

## YOLO 对比框架

- 新增 `yolo_compare.py` 脚本
- 检测 ultralytics 是否安装，未安装给出安装提示
- 如已安装，使用 yolov8n.pt 通用模型对样本图片进行推理
- 生成对比 CSV 报表：`outputs/reports/yolo_compare_report.csv`
- YOLO 结果图保存到：`outputs/yolo/`

## 重要说明

**当前不是完整的 YOLO 训练项目。**

- 脚本使用 yolov8n.pt 是 COCO 数据集预训练的通用目标检测模型
- 该模型能检测人、车、动物等 80 类 COCO 目标，但**不能**检测工业缺陷
- 真正的工业缺陷检测需要：
  1. 收集并标注真实缺陷图片数据集
  2. 使用 YOLO 进行迁移学习 / 微调
  3. 在验证集上评估模型性能

## 项目定位

- **OpenCV 规则方法**：当前项目的核心检测方案（基线）
- **YOLO 对比框架**：后续深度学习扩展方向（预留）

## 后续如果扩展

- 收集真实工业缺陷图片，按缺陷类型分类标注
- 使用 LabelImg 或 CVAT 标注边界框
- 训练 YOLOv8 模型并微调
- 对比 OpenCV 规则方法和 YOLO 在真实数据上的表现
- 将训练好的模型集成到实时检测和 GUI 中
