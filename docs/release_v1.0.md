# V1.0 版本说明：真实工业缺陷数据验证版

## 1. 版本定位

V1.0 是从模拟样例升级到真实工业数据验证的版本。使用 KolektorSDD2 风格的真实工业表面缺陷数据集，在 60 张真实样本上验证 OpenCV 传统规则方法的实际表现。

## 2. 相比 V0.5 的提升

- 从程序生成的模拟图片升级到真实工业缺陷图片
- 增加真实 OK / NG 样本子集（各 30 张）
- 在真实数据上统计 TP、TN、FP、FN
- 增加典型成功案例（TP/TN）和失败案例（FN）分析
- 增加详细的真实数据集分析报告
- 项目可信度从"概念验证"提升到"真实数据验证"

## 3. 新增功能

| 文件 | 说明 |
|------|------|
| `src/real_dataset_detector.py` | 真实数据集检测模块，支持从文件夹读取 OK/NG 样本并执行 OpenCV 检测 |
| `scripts/run_real_dataset.py` | 真实数据批量检测运行脚本，统计 TP/TN/FP/FN 并保存 CSV 报表 |
| `docs/real_dataset_analysis.md` | 真实数据集详细分析报告（含指标、案例、局限、改进方向） |
| `docs/images/real_cases/` | TP/TN/FN 典型案例标注图 |
| `data/real_samples/OK/` | 真实 OK 样本子集（30 张） |
| `data/real_samples/NG/` | 真实 NG 样本子集（30 张） |
| `outputs/real_dataset/` | 真实数据检测输出（标注图、处理图、报表） |

## 4. 真实数据实验结果

在 60 张真实工业缺陷样本上的检测结果：

| 指标 | 数值 |
|------|------|
| TP | 3 |
| TN | 30 |
| FP | 0 |
| FN | 27 |
| Accuracy | 55.0% |
| Precision | 100.0% |
| Recall | 10.0% |

模拟图片 100% 准确率 → 真实数据 55%，Recall 仅 10%。

## 5. 当前局限

- 固定阈值 GRAY_THRESHOLD=200 是为模拟图片设计的，在真实数据上严重不适配
- 30 张 NG 样本中有 27 张漏检，缺陷灰度与背景接近
- 样本规模有限（60 张），不能代表全部真实工业场景
- 未使用像素级 GT mask 做更精细的评估

## 6. 后续计划

- Otsu 自适应阈值替代固定阈值
- 局部自适应阈值实验

- 反转阈值逻辑（检测暗缺陷 vs 亮缺陷）

### V2.0（长期）

- YOLO 缺陷检测模型训练
- OpenCV vs YOLO 在真实数据上的量化对比
