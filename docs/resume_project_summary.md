# 工业零件表面缺陷检测与分拣模拟系统 — 简历项目总结

## 1. 项目一句话介绍

基于 OpenCV + CLAHE 的工业表面缺陷检测系统，在 1004 张真实工业样本上完成传统视觉方法全流程验证与系统性参数实验。

## 2. 技术栈

Python · OpenCV · NumPy · Matplotlib · CLAHE · 形态学处理 · tkinter · Git/GitHub

## 3. 核心功能

- 批量图像读取与预处理（灰度化、CLAHE 增强、形态学开闭运算）
- 阈值分割 + 轮廓检测 + 缺陷面积统计
- OK/NG 自动判定与缺陷框标注
- TP/TN/FP/FN 混淆矩阵统计
- Accuracy / Precision / Recall / F1 多指标评价
- CSV 检测报表与实验记录自动保存
- 多阈值参数网格搜索（100+ 组）
- 传统视觉增强方法对比（CLAHE / Top-hat / Black-hat / Sobel / Canny）
- tkinter GUI 可视化操作界面
- 摄像头实时检测（OpenCV VideoCapture）
- YOLO 对比框架（可选扩展）
- Matplotlib 实验结果可视化图表

## 5. V1.1 与 V1.2 关键指标对比

| 版本 | 方法 | TP | TN | FP | FN | Accuracy | Precision | Recall | F1 |
|------|------|----|----|----|----|----------|-----------|--------|-----|
| V1.1 基线 | 固定阈值 gray=200 | 5 | 894 | 0 | 105 | 89.5% | 100.0% | 4.5% | 0.087 |
| V1.1 最佳 Rec | 固定阈值 gray=60 | 110 | 41 | 853 | 0 | 15.0% | 11.4% | 100.0% | 0.205 |
| **V1.2 CLAHE** | **CLAHE gray=100** | **65** | **880** | **14** | **45** | **94.1%** | **82.3%** | **59.1%** | **0.688** |

CLAHE 增强将 F1 从 0.087 提升到 0.688（7.9 倍），在 Precision 和 Recall 之间取得了有效平衡。

## 6. 最终最佳结果

**方法**：CLAHE（clip_limit=2.0）+ 固定阈值（gray=100）+ 形态学（kernel=5, 开+闭）+ 面积阈值（area=100）

## 9. 面试讲法

这个项目是我用来系统学习工业机器视觉流程的。我选了一个 KolektorSDD2 风格的工业表面缺陷数据集，里面有 1004 对原图和像素级标注的 GT mask。

我的思路是先跑基线——用最简单的固定阈值方法，结果是 Recall 只有 4.5%，110 个缺陷只检出 5 个。然后我做了 100 多组阈值参数的网格搜索，发现可以调到 100% Recall，但代价是 853 个误报——等于把几乎所有 OK 都判成了 NG，这在实际产线完全不可用。

之后我换了一个思路：问题不在分类（面积阈值），而在分割（二值化）。缺陷和背景的灰度对比度太低，普通阈值切不干净。所以我尝试了 CLAHE、Top-hat、Black-hat、Sobel、Canny 这些增强方法，用 54 组实验对比。CLAHE 效果最好，把 F1 从 0.087 提到了 0.688。

这件事让我理解了两点：一是传统方法仍然有价值，一个 CLAHE 就能带来 7.9 倍的 F1 提升；二是传统方法确实有天花板——F1 大概卡在 0.7 左右，再往上需要深度学习来突破。所以我下一步计划用 YOLO 训练一个缺陷检测模型，和当前的 CLAHE 方案做量化对比。

## 10. 项目局限与后续 YOLO 计划

**当前局限**：
- F1=0.688 仍有提升空间，45 个缺陷漏检
- CLAHE 参数仍需人工调试，缺乏自适应能力
- 仅使用图像级标签（OK/NG），未利用 GT mask 做像素级 IoU 评估
- 测试集 1004 张规模有限

**后续 YOLO 计划（V2.0）**：
- 使用 GT mask 生成 YOLO 格式边界框标注
- 训练 YOLOv8 缺陷检测模型
- 在同一 test 集上对比 CLAHE 和 YOLO 的 Precision / Recall / F1
- 像素级分割模型（U-Net）验证
- 绘制 CLAHE vs YOLO 的 Precision-Recall 对比曲线
