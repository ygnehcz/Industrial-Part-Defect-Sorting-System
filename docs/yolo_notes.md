# YOLO 对比说明

## OpenCV 规则方法特点

- 基于固定阈值和形态学处理
- 不需要训练数据，规则可解释
- 计算量小，适合嵌入式设备
- 对光照和纹理变化敏感
- 适合缺陷类型简单、背景干净的场景

## YOLO 深度学习方法特点

- 基于卷积神经网络学习特征
- 需要大量标注数据进行训练
- 对复杂场景和多样化缺陷鲁棒性强
- 可以同时检测和分类多种缺陷类型
- 推理速度依赖 GPU 硬件

## 两者对比

| 维度 | OpenCV 规则方法 | YOLO 深度学习 |
|------|----------------|--------------|
| 数据需求 | 无需训练数据 | 需要标注数据集 |
| 开发周期 | 短，规则可快速调整 | 长，需要标注+训练+验证 |
| 泛化能力 | 弱，场景变化需调参 | 强，可适应新场景 |
| 硬件要求 | 低，CPU 即可 | 较高，推荐 GPU |
| 可解释性 | 高，每步可见 | 低，黑盒特征 |
| 缺陷分类 | 难 | 易，一次推理多类别 |

## 当前项目为什么先做 OpenCV

1. OpenCV 方案快速可验证，适合学习图像处理基础
2. 不需要大型标注数据集即可运行
3. 流程透明，便于理解每个步骤的作用
4. 作为基线方案，后续可和 YOLO 做量化对比

## 后续如何训练 YOLO 缺陷检测模型

1. **数据收集**：采集真实工业零件表面图片（OK 和各类 NG）
2. **数据标注**：使用 LabelImg / CVAT 标注缺陷位置和类别
3. **数据集划分**：按 7:2:1 划分训练集、验证集、测试集
4. **模型训练**：
   ```bash
   from ultralytics import YOLO
   model = YOLO("yolov8n.pt")
   model.train(data="defect_dataset.yaml", epochs=100)
   ```
5. **模型验证**：在验证集上评估 mAP、Precision、Recall
6. **模型部署**：导出 ONNX 或 TensorRT 格式用于产线部署
